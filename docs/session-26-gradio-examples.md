# Session 26: Gradio Example Claims

## What We Added

The LangGraph Gradio app now includes clickable example claims.

These examples make the demo easier to present because you do not need to type a claim manually each time.

## Example Types

The examples are chosen to demonstrate different behavior:

1. Local retrieval
2. Wikipedia fallback
3. Contradicted sports claim
4. Not-enough-evidence behavior

## Why This Helps

A good demo should quickly show:

```text
what the system can do
where evidence came from
how verdicts change depending on evidence
```

Example claims make that easier.
